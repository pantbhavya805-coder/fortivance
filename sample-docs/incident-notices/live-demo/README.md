# Live demo notice

`PR-SEC-2026-0031.md` is a fresh incident for recording or presenting a demo with a running RBI 6-hour clock.
The three notices one folder up are historical incidents used by the Evaluation page; do not change their dates.

The clock counts from the **Detected** time. Before recording on another day, edit these three lines to today's date
and a detection time about an hour before you start, so the countdown shows several hours left:

- `**Sent:**` (for example 45 minutes after detection)
- `**Detected:**`
- `**Next update:**`

Each edit is a new document, so the first upload runs Claude again (a few cents); re-uploading the same file is free.
